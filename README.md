DeepSeekChat —— 让鲸鱼娘可以和你聊天！

项目简介

DeepSeekChat 是一个纯前端、立绘驱动的 AI 对话应用。它把枯燥的文本回复变成了有表情、有特效、有音效的沉浸式交互体验。顺带一提：该项目百分百纯AI手艺制作，传统人工代码零添加。

你发消息，AI 流式回复；回复中页面上的角色立绘会随语境会自动切换对应情绪，同时触发烟花、花瓣、雨滴、愤怒环等视觉特效和情绪音效。

---

核心功能

流式对话：AI 回复逐字输出，像真人打字一样。

情绪立绘：八种情绪驱动立绘切换，包括常态、开心、惊喜、愤怒、思索、悲伤、紧张、傻乐呵、干饭。

视觉特效：情绪触发对应粒子特效，惊喜触发烟花，开心触发花瓣飘落，悲伤触发雨滴，愤怒触发红色脉冲环。

音效系统：打字音效加情绪切换音效，使用 Web Audio 实时合成，无需外部音频文件。

多模态支持：上传图片随消息发送，支持多模态 AI 识别。

多对话管理：支持新建、切换、重命名、删除对话，本地持久化存储。

多协议兼容：支持 OpenAI 协议、Anthropic 协议以及完全自定义协议。

双主题：日间、夜间、跟随系统三种模式，毛玻璃拟态设计。

响应式适配：桌面端和手机端自适应布局。

日志系统：记录 API 请求、错误信息、情绪切换轨迹，方便调试。

情绪特效对照

情绪标签为常态时，立绘切换为 normal.png，无视觉特效，无音效。

情绪标签为开心时，立绘切换为 happy.png，触发花瓣飘落特效，伴随轻快上行音效。

情绪标签为惊喜时，立绘切换为 surprised.png，触发烟花爆炸特效，伴随低鸣加高频星点音效。

情绪标签为愤怒时，立绘切换为 angry.png，触发红色脉冲环特效，伴随低频锯齿波音效。

情绪标签为思索时，立绘切换为 thinking.png，无视觉特效，无音效。

情绪标签为悲伤时，立绘切换为 sad.png，触发雨滴下落特效，伴随下行忧郁音效。

情绪标签为紧张时，立绘切换为 nervous.png，无视觉特效，无音效。

情绪标签为傻乐呵时，立绘切换为 silly.png，无视觉特效，无音效。

情绪标签为干饭时，立绘切换为 eating.png，无视觉特效，无音效。

非默认情绪三十秒后自动恢复常态。

技术栈

原生 JavaScript ES6+ 编写全部业务逻辑，无任何框架依赖。

CSS3 实现毛玻璃拟态、双主题切换、过渡动画和响应式布局。

HTML5 语义化结构，支持无障碍访问。

Web Audio API 实时合成音效，无需外部音频文件。

Canvas 2D API 渲染粒子特效，包括烟花、花瓣和雨滴。

Fetch API 配合 ReadableStream 处理流式 AI 响应。

localStorage 实现对话历史、设置和日志的持久化存储。

SSE 解析流式响应数据。

运行时零依赖，除了开发工具外不需要安装任何第三方库。

项目结构

根目录下包含 index.html 主页面文件。

styles.css 样式文件，负责毛玻璃效果、双主题和动画。

app.js 核心逻辑文件，处理聊天、API 请求、情绪切换、音效和特效。

DeepSeekChat图标.jpg 作为站点图标。

assets 目录存放所有透明背景的立绘 PNG 图片，包括 normal.png、happy.png、surprised.png、angry.png、thinking.png、sad.png、nervous.png、silly.png 和 eating.png。

tools 目录下包含 process-assets.js 预处理脚本，用于将绿幕原图处理为透明 PNG。

package.json 声明依赖 pngjs，用于图片处理。

package-lock.json 锁定依赖版本。

快速开始

首先克隆项目到本地。

然后用浏览器直接打开 index.html 即可运行，无需启动任何服务。

首次打开会弹出引导提示，点击去设置进入配置页面。

在设置中填写 API Key 和 Base URL。

点击测试连接并获取模型按钮，系统会自动拉取可用模型列表。

在顶部下拉框选择模型，即可开始聊天。

如果使用自定义协议，可以选择自定义协议选项，自行配置请求路径、方法、请求体模板、响应提取路径和流式开关。

---

配置说明

运行环境要求现代浏览器，包括 Chrome、Firefox、Edge 或 Safari，支持 ES6+、Fetch API、ReadableStream 和 Web Audio API。

本项目为纯前端应用，无需 Node.js 环境。

所有数据保存在浏览器 localStorage 中，包括设置项、对话历史、当前对话 ID 和日志记录。

注意数据仅适合本地个人使用，不支持多设备同步。
