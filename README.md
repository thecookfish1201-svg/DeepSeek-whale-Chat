DeepSeek—Whale—Chat 【DWC】 是一个纯前端、立绘驱动的 AI 对话应用。用户发送消息后，AI 以流式形式回复，回复内容中的情绪标签会驱动角色立绘切换，并触发对应的视觉特效与音效。

---

核心功能


情绪立绘：支持常态、开心、惊喜、愤怒、思索、悲伤、紧张、傻乐呵、干等数种情绪状态，每种情绪对应独立的立绘资源。

视觉特效：惊喜触发烟花粒子效果，开心触发花瓣飘落，悲伤触发雨滴下落，愤怒触发红色脉冲环动画。

音效系统：打字音效与情绪切换音效均通过 Web Audio API 实时合成，无需外部音频文件。

多模态支持：支持上传图片随消息发送，适配支持视觉识别的 AI 模型。

对话管理：支持新建、切换、重命名、删除对话，数据持久化存储于浏览器本地。

多协议兼容：支持 OpenAI 协议、Anthropic 协议及完全自定义协议，可接入任意兼容 API。

双主题：提供日间与夜间两种视觉主题，支持跟随系统偏好自动切换。

日志系统：记录 API 请求、错误信息及情绪切换事件，便于调试。

---

技术实现

项目采用原生 JavaScript ES6+ 编写，无任何第三方框架依赖。CSS3 实现毛玻璃拟态效果与双主题切换。Canvas 2D API 负责粒子特效渲染。Fetch API 配合 ReadableStream 处理流式响应。localStorage 用于持久化存储。

立绘切换采用双图层交叉淡入淡出机制，确保过渡平滑无闪烁。情绪特效与音效联动触发，非默认情绪在三十秒后自动恢复常态。

---

项目结构

· index.html：主页面
· styles.css：样式定义
· app.js：核心业务逻辑
· assets/：立绘图片资源
· tools/process-assets.js：绿幕原图预处理脚本

---

运行方式

安装apk文件或获取开源的文件进行使用即可，随你发挥，无需启动后端服务。首次使用时需在设置中配置 API Key 与 Base URL，点击获取模型后即可开始对话。

---

适用场景

适合希望为 AI 对话赋予视觉化角色形象的场景，可作为个人助手、虚拟陪伴或交互式演示的原型。
