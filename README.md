# DeepSeekChat

纯前端 Web 应用：与 DeepSeek 角色进行流式对话，AI 回复中的 `[emotion=惊喜]` 等标签会驱动立绘、音效与视觉特效。

## 文件结构

```
index.html          # 主页面
DeepSeekChat-单文件测试版-v1.4.0.html  # 单文件测试版 v1.4.0（CSS/JS/立绘全部内嵌）
styles.css          # 样式（毛玻璃、日/夜主题、动效）
app.js              # 应用逻辑（聊天、流式 API、情绪、音效、特效、设置）
assets/             # 已处理好的透明 PNG 立绘
tools/process-assets.js   # 原始 PNG -> assets 的预处理脚本
DeepSeekChat图标.jpg      # 站点图标
```

## 使用方法

1. 用浏览器打开 `index.html` 或 `DeepSeekChat-单文件测试版-v1.4.0.html`。
2. 首次打开会提示配置 API Key。
3. 在设置中填写 API 信息并选择协议。
4. 点击“测试连接并获取模型”后，可在聊天卡片顶部的“模型选择器”中直接切换已拉取到的模型。
5. 发送消息即可看到流式输出、立绘情绪切换、固定间隔打字音效和对应特效。
6. 日志入口已移动到 设置 → 日志，点击“打开日志面板”查看。

## 交互说明

- 点击立绘会有抖动反馈和音效。
- 烟花、花瓣、雨滴、愤怒环等情绪特效会附带对应的轻量音效。
- 切换到的非默认情绪会在 30 秒后自动回到默认状态；本来就是默认状态则不会切换。

## 提示词

- 设置中可直接编辑当前对话 System Prompt。
- 提示词可以留空，不强制填写。
- 输入后会自动保存，切换对话不会丢失。

## 自定义协议

选择“自定义协议”后，需要自行填写：

- Base URL
- 请求路径
- 请求方法
- 请求体模板（JSON，支持 `{{model}}`、`{{messages}}`、`{{system}}` 等变量）
- 响应文本提取路径
- 是否流式响应
- 可选：自定义模型列表地址与提取路径

自定义协议不会自动套用任何预设请求格式。

## 注意

- API Key 保存在浏览器 `localStorage`，仅适合本地个人使用。
- 若浏览器拦截跨域，可在设置中开启“代理”并填写本地/CORS 代理前缀。
- 所有图片资源均由 `tools/process-assets.js` 从绿幕原图自动生成。
- 重新处理原图前需执行 `npm install`。
